# Legacy provider migration

OpenArt Seedance 2.5 Draft is the provider for new jobs. Enhancor, Replicate, temporary hosting and webhook routing are no longer active. Dreamina settings and state are retained only for collecting existing Dreamina jobs.

Preserve source files, artifacts and provider identities for older jobs. Never silently resubmit a legacy job through OpenArt. Existing Enhancor jobs must be retrieved from their original provider, then imported for audio restoration if needed.

See [OPENART.md](OPENART.md) for the current contract and [DREAMINA.md](DREAMINA.md) for historical Dreamina limits.
